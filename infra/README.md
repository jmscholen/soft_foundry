# Infrastructure

Application-owned infrastructure belongs here when its lifecycle and ownership are coupled to the application. Preserve the repository's existing IaC technology rather than imposing one.

Recommended concerns include environments, reusable modules, networking, compute/runtime, database, storage/cache, load balancing, IAM/security, DNS, observability, dashboards, alarms, metric filters, SLOs, and deployment/policy tests.

Infrastructure changes follow the same Soft Foundry change lifecycle as application changes.
