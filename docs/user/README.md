# User Documentation

This directory is the canonical product-facing knowledge base for instructions and FAQ content. User instructions should be promoted here only when grounded in successfully completed evaluation journeys. Records should retain provenance to requirement IDs, EVAL IDs, introducing change, and last verified change.

When a later change modifies a validated journey, dependent documentation must be marked for revalidation rather than assumed current.
