## Residuals this model accepts up front
- A committer can forge any field (TB-4). Each new check turns a silent omission into a written falsehood in a commit; it does not prevent the falsehood.
- A shell that unsets `SOFT_FOUNDRY_PHASE` can seal another phase (MIT-001), as it can already release or reopen.
- An alias-expansion YAML document can make a gate slow (MIT-010).
- A hand-committed handoff is recorded without a seal (MIT-009); the seal's value is that nobody has to remember, not that nobody can.
