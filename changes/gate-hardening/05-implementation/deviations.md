Each deviation records what changed, why the plan could not be followed, which requirements are affected, and who must approve it.

1. **Test placement.** `04-plan/testing.md` named new test methods inside ten existing files. The RED commit put them in five new files instead (`test/phase_seal_test.rb`, `test/gate_checks_test.rb`, `test/fixture_completion_test.rb`, `test/phase_run_sealing_test.rb`, `test/gate_hardening_cli_test.rb`), with the method names the plan listed. Requirements affected: none (the coverage table's tests exist under the planned names). Approval: plan owner; recorded here.

The expectations are unchanged; the fixture call states the intent. Requirements affected: REQ-014's fixture interaction (SPEC-002). Approval: none needed; no expectation was weakened.
