# Mitigations

| ID | Threats | Mitigation | Where enforced | Verified by |
| --- | --- | --- | --- | --- |
| MIT-001 | THREAT-001 | Staleness includes edits to the record's scope, `shared_core`, `access_control` and the sizing policy after the evidence commit, diffed by path and compared against the evidence commit's own value. Declarations live in protected paths for execution sessions. | `staleness_check` in gate; permissions of every execution skill | Attack case AC-X1; a gate harness-eval planting a narrowed scope; unit test for declaration-change staleness (AC-007) |
| MIT-002 | THREAT-002 | `soft-foundry check` and the gate refuse empty, absolute, `..` and match-nothing globs, and a shared-core glob matching no code-group path; failure names the glob and the fix. | `check` and gate structure checks | AC-X6; harness-eval with a blind core glob; test (AC-015) |
| MIT-003 | THREAT-003 | Claimed-by-other uses only records that are active (not closed) and well-formed; a path claimed by another record still stales a record when it lies in the shared core or when this record's scope matches it; unclaimed paths stale all; overlapping scopes and a scope matching no changed file raise advisories; report names the claiming record per path. Remaining risk: two active records mis-declaring overlap is a reviewer judgment, surfaced by REQ-020 output. | Staleness and advisory modules | AC-X2; test with a closed record holding `**`; test of overlap advisory |
| MIT-004 | THREAT-004 | Tree hash is recomputed from the evidence commit and compared with the cited record's recorded hash and the citing commit's tree; outcome must be `passed`; slug validated and resolved under `changes/` only; citation depth one, no self or cyclic citation; the recorded hash alone is never trusted. Residual: the outcome text is a claim by the recording session; the gate states it is structural (REQ-008), and review judges it. | Gate full-suite check | AC-X3; tests for missing record, wrong tree, outcome not passed, self-citation (AC-008, AC-009) |
| MIT-005 | THREAT-005 | Reuse refused when any code path is dirty; the message states that untracked and ignored files are outside the tree hash. Residual: ignored files that alter behaviour but are not code paths remain a recorded limitation. | Gate full-suite check using one `git status` call | AC-X4; test with a dirty file |
| MIT-006 | THREAT-006 | Size computed from the diff and declared globs by a policy in `.ai/policies/`, with no declaration meaning full; the gate refuses recorded sizes below the computed size; targeted sizing never removes a check with a criterion in the record and the pre-merge full run stays required. | Sizing module, gate size check, policy file | AC-X5; tests for each size outcome (AC-011 to AC-014) |
| MIT-007 | THREAT-007 | Every git call checks exit status; unknown commit, tree or branch yields stale or check failure naming the cause; no use of empty output on error as "no change". | `Git` wrapper and staleness check | AC-X7; tests that stub git failure (AC-016) |
| MIT-008 | THREAT-008 | Equality of tree hash is the only reuse key; a miss fails the reuse check with an instruction to run and record the suite. | Gate full-suite check | AC-X8; test with a rebased tree (AC-009) |
| MIT-009 | THREAT-009 | Globs are matched in-process against repository-relative git paths; git is invoked with argument arrays and `--`; slugs match the record-name pattern; YAML via safe loader without aliases for new declarations; control characters refused. | Control plane, git wrapper, check | AC-X9; test with hostile strings (AC-015) |
| MIT-010 | THREAT-010 | A bounded number of git invocations independent of file count; each record read once; the glob matcher must not backtrack catastrophically (plan to confirm the existing matcher or bound pattern complexity). | Gate and sizing modules | Test counting git calls with large diffs (AC-022) |
| MIT-011 | THREAT-011 | Output states scope, causing paths and reasons; reuse output says it is recorded evidence, structural only; docs carry the same wording; words not colour for outcomes. | CLI output, docs, status | AC-X10; text assertions (AC-010, AC-019) |
| MIT-012 | THREAT-012 | The view consumes the gate's single scoped result with no logic of its own; scope and paths are escaped on output; stale conveyed in text. | UI and snapshot | Test with an HTML-bearing glob; view test (AC-018, AC-020) |
