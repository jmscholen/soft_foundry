# Mitigations

| ID | Threats | Mitigation | Where enforced | Verified by |
| --- | --- | --- | --- | --- |
| MIT-001 | THREAT-001 | The Host header must be `127.0.0.1:PORT` or `localhost:PORT`; anything else, or none, is 403 on every route. | `UI::Server#own_host?` | `test_a_host_header_that_is_not_this_server_is_refused`; ATTACK-002 |
| MIT-002 | THREAT-002 | Data routes refuse `Sec-Fetch-Site` other than `same-origin` or `none`. No CORS header is ever sent. Data is `application/json` with `nosniff`. `frame-ancestors 'none'`. | `UI::Server#respond`, `HEADERS` | `test_a_request_for_data_that_another_site_made_is_refused`, `test_every_response_carries_the_protective_headers`; ATTACK-003 |
| MIT-003 | THREAT-003 | Six exact-match routes; the three files are read from constant paths; a slug is used only if `ChangeIndex#slugs` returned it. | `UI::Server::STATIC`, `#respond`, `#change` | `test_only_the_six_routes_exist`, `test_an_unknown_or_hostile_slug_is_not_found`; ATTACK-001 |
| MIT-004 | THREAT-004 | The page builds DOM with `createElement` and `textContent` only; the CSP allows no inline or remote script or style. | `app.js` `el`/`add`; `UI::Server::HEADERS` | `test_script_never_parses_strings_as_markup_or_code`, `test_page_has_nothing_inline_and_nothing_remote`, `test_record_text_is_returned_as_json_not_markup`; ATTACK-007 |
| MIT-005 | THREAT-005 | Only GET and HEAD are answered; no handler writes to disk. | `UI::Server#respond` | `test_other_methods_are_refused`; ATTACK-004 |
| MIT-006 | THREAT-006 | 8 KB header cap, 2 s read deadline, a thread per connection, sixteen connections with the longest-idle one evicted when full, 2 s reuse of API answers, one computation at a time. | `UI::Server#read_request`, `#admit`, `#cached` | `test_malformed_and_oversized_requests_are_refused`, `test_a_silent_connection_is_dropped_without_blocking_others`, `test_silent_connections_cannot_crowd_out_a_request`, `test_api_answers_are_reused_briefly`; ATTACK-005, ATTACK-006 |
| MIT-007 | THREAT-007 | The listener binds 127.0.0.1; there is no option to bind anything else. | `UI::Server::ADDRESS`, `CLI#ui` | `test_it_listens_on_loopback_only`, `test_a_bad_port_or_option_is_refused_before_anything_starts`; ATTACK-009 |
| MIT-008 | THREAT-008 | Accepted, not mitigated: no token. The server is read-only and says so when it starts. A per-run URL token is the mitigation if a shared machine becomes a use. | Recorded here and in `13-review/security.md` | n/a |
| MIT-009 | THREAT-009 | A snapshot emits only named fields, never file content; a metadata file that is not a mapping is refused by name. | `Snapshot#metadata`, `#summary` | `test_a_metadata_file_that_is_not_a_mapping_is_named_plainly`; ATTACK-008 |
| MIT-010 | THREAT-010 | The request line must match `VERB /target HTTP/1.x`; reading stops at the end of the headers; one response per connection, then close. | `UI::Server::REQUEST_LINE`, `#read_request`, `#handle` | `test_malformed_and_oversized_requests_are_refused`; ATTACK-006 |
