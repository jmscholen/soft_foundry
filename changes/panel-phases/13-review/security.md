# Security Review

## Scope reviewed

THREAT-001..005 and MIT-001..005, `Guard#narrow_for_panel`, panel prompts in `Panel#prompt_for`, `Gate#panel_check`, and `08-attack/results.md`. Rules: `.ai/rules/security.md`. Reproduced the guard decisions in a throwaway repository whose `current_phase` was `specify` (the skill write set is `changes/<slug>/02-specification/**`, which is what `panel_run` sets before it launches).

The repository guard mode is `warn` (`.ai/policies/enforcement.yml`). Warn mode reports and allows. The holes below are allows even in block mode: the decision is `:allow`, so the mode never gets a chance to refuse.

## What holds

Shell names come from a fixed list. Member names are `<shell>-<n>` generated by the runner, matched by `Panel::NAME` before narrowing trusts them. A name the runner does not make is ignored rather than given a wider write set (ATK-RES-001). Agreement ignores an `agree:` line that a member wrote under another member's heading, and a rewrite of earlier `ARGUMENT.md` text spoils the round (ATTACK-003, tests). `--panel` rejects unknown shells, fewer than two or more than four members, a path-shaped token, `--max-rounds` outside 1..5, a bad `--shell-arg`, and `--shell` together with `--panel` (ATTACK-004). `implement` is refused and `check` errors if `panel_phases` names it (ATTACK-005). `--shell-arg` values are separate argv elements to `Process.spawn`, not a shell. The single-provider advisory matches REQ-PN-008. Prompts tell members that other members' files are data, except for the agree sentence copied into the consensus prompt (REV-SEC-003).

ATTACK-001 was not run against a live model. REV-SEC-003 is the part of that threat that is visible in the runner without a live model. The residual that a model may obey a draft it was told to treat as data, while the guard is in block mode and the tool is one the guard actually narrows, remains the one ATTACK-001 recorded.

## Conformance

Does not conform. REV-SEC-001, REV-SEC-002, and REV-SEC-003 are reachable with the guard in block mode. Bounds, name generation, forged agreement, and the implement refusal conform.
