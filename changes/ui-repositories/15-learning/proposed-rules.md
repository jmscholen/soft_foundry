# Proposed Rule Changes

Proposals are not self-applied. Each becomes a governance change against `.ai/` that follows the standard lifecycle.

| --- | --- | --- | --- |
| Re-rate carried findings | `.ai/skills/review/SKILL.md` | REV-002 | "A finding carried from an earlier change is re-rated, not copied: if it has since caused a fault, it is at least major." |
| Code that runs in a browser is run by a test | `.ai/rules/testing.md` | REV-002 | "A script served to a browser has at least one test that executes it; assertions on its source text are not a substitute." |
