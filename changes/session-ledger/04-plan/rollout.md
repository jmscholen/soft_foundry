# Rollout

- Ships in 0.18.0 like every release: built and installed locally under the asdf Ruby the global wrapper uses (never pushed to RubyGems).
- Nothing changes for anyone until they run `soft-foundry hooks install --sessions`; the guard's Grok mapping applies as soon as the new version runs.
- Installing on the maintainer's own configuration is a separate step they approve after the change merges.
