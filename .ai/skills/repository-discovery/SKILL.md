# Repository Discovery
Determine what exists before proposing change. Distinguish discovered facts, inferred facts, defined policy, and unknowns. Inspect architecture, runtime, tests, security boundaries, infrastructure, and operational conventions. Do not modify product code. Locate the application's published privacy policy, security policy, and terms (or establish that none exist) and record them under `policies:` in `.ai/repository.yml` per `.ai/rules/policy-conformance.md`; a missing document is recorded as MISSING, never silently omitted.
