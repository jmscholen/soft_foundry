# Git Standard

- Work on the assigned branch/worktree and preserve unrelated user changes.
- Do not use destructive history or working-tree commands such as forced resets or broad cleans unless explicitly authorized.
- Commits should represent coherent changes and must not intentionally hide failed evidence or unrelated modifications.
- Never commit secrets, local runtime configuration, provider credentials, or `.soft-foundry/` state.
- Pull requests must describe intent, design decisions, validation performed, material risks, and known limitations.
